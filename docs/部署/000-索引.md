## 给 Codex 的领取说明

1. 扫描本表，找到状态为 `待领取` 的行。
2. 打开对应编号文档，**先通读全文再动手**。
3. 把该文档头部状态改为 `进行中`，并写下开始时间。
4. 执行任务，材料落盘到文档指定的路径。
5. **在文档末尾的「Codex 回复区」作答**（进度 / 自行判断 / 疑点 / 交付物）。
6. 把文档头部状态改为 `已完成`，并同步更新本索引表的状态列。

**注意**：按 `docs/项目规范/agent协作规范.txt`，Codex **绝不主动中断**。遇到不确定之处，**记录疑点 + 自行判断 + 继续推进**，不要停下等待。
