## 一、任务目的

团队要参加「正大杯」，但**赛事的规则细节尚未核实过**。在确定选题方向之前，必须先把这个赛事的**客观约束**摸清楚 —— 因为选题的自由度、评审的偏好、提交物的硬性要求，都会直接决定"什么方向是可行的、什么方向是死路"。

本任务**只做事实核查与采集**，不做选题建议。选题建议由 Claude Code 在后续阶段基于你产出的材料来做。

**重要**：本任务的价值在于**准确**，不在于**多**。宁可条目少而可靠，也不要凑数。

## 二、必须回答的问题清单

请逐项作答。**答不上来的，明确写"未能核实"，不要编造或推测。**

### A. 赛事主体（基本盘）
1. 赛事**全称**、**主办单位**、**承办单位**、**赞助/冠名方**、**指导单位**。
2. 赛事**创办年份**、已举办**届数**、**最近一届**是哪一届、下一届（即当前备赛的这一届）的时间。
3. 赛事在高校中的**定位与层级**（是否属于教育部认可的学科竞赛榜单，如中国高等教育学会《全国普通高校大学生竞赛榜单》——若在榜，注明类别与排名口径）。

### B. 参赛规则（决定可行性）
4. 参赛**资格**：年级、专业限制、是否允许跨校/跨院组队。
5. **组队规则**：每队人数上下限、指导教师人数、是否允许研究生、每校报名队数上限。
6. **报名与晋级路径**：是否分校赛 → 省赛 → 全国赛？各阶段名称、晋级比例或名额。
7. **关键时间节点**：报名截止、校赛/省赛/国赛时间、报告提交截止（尽量给出**最近一届的实际日期**作为参照）。

### C. 赛道与组别（决定选题策略）★ 本次最关键
8. 赛事设有**哪些赛道 / 组别**？请**穷尽列出**，例如（仅为举例，需核实真实名称）：
   - 是否设有**企业命题赛道**（如正大集团命题）？若有，命题清单在哪里发布、有哪些题目？
   - 是否有**自主选题赛道**？
   - 是否有**留学生组 / 研究生组 / 专科组**等分组？
9. 各赛道的**差异**：选题自由度、评分侧重、竞争强度、获奖比例。
10. **企业命题赛道**的题目：若存在，请**完整抄录**最近一届的命题题目与要求说明，并给出出处链接。

### D. 提交物与评审（决定工作重心）★ 本次最关键
11. **最终提交物**是什么？（调研报告？现场答辩？PPT？数据附件？）各自的形式与篇幅要求（字数、页数、格式模板）。
12. **评审标准与评分权重**：评分表有哪些维度、各占多少分。**请务必找到原始评分细则**，不要用二手转述。
13. **是否强制要求实地调研 / 一手数据**？对样本量、抽样方式有无硬性规定？
14. 对**数据分析方法**有无要求或偏好（如必须使用某种统计方法）？
15. **红线与违规判定**：数据造假、抄袭、AI 使用的规定、往届被取消资格的案例及原因。

### E. 往届参照（判断"什么选题能赢"）
16. **最近 2–3 届的获奖作品题目清单**：尽量收集国家级一、二、三等奖的**作品标题**（标题本身就透露了选题类型与尺度），注明届次与来源。
17. 若有公开的获奖作品全文或摘要，收集其中 **2–3 份代表作**的关键信息（选题、数据来源、方法）。
18. 往届**选题类型分布**的观察：例如偏消费市场、偏数字经济、偏乡村振兴、偏企业命题等，是否有明显聚集。

### F. 与 AI / 技术相关的特别线索
19. 赛事是否设有**与 AI、大数据、数字经济相关的专项奖或命题**？
20. 往届获奖作品中，是否有以**AI 技术或数据方法本身**为亮点（而非仅作为分析工具）的作品？

## 四、来源要求（硬性）

**每一个事实性结论都必须标注来源。** 格式建议：

```
结论：<一句话结论>
来源：<网页标题> <URL>  访问日期 2026-10-15
证据强度：强 / 中 / 弱
```

**证据强度判定标准**：
- **强**：赛事官网、主办方（中国商业统计学会等）官方文件、官方发布的评分表/章程原文。
- **中**：高校教务处/学院官网通知、官方公众号推文、权威媒体报道。
- **弱**：论坛、自媒体、问答网站、个人博客、培训机构页面。

**当多个来源冲突时**：全部列出，并注明冲突点，不要自行裁决。**优先采信官网**。

**时效性**：优先取最近一届（第 15 届前后）的信息。若只找到往届信息，注明是哪一届。

## 七、遇到不确定时怎么办

**不要停下等待。** 按以下顺序处理：

1. 换一个来源再试（例如官网找不到，就找高校教务处转发通知）。
2. 尝试的**途径**要记录下来，写进回复区的「疑点」栏（例如"搜索了 X、Y、Z，官网 XX 栏目为空"）。
3. 若仍无结果，写「未能核实」，并**给出你判断的最可能情况**，标注为「推测，未核实」。
4. **继续推进下一题**，不要卡在单题上。

**特别注意**：绝对不要用记忆或推测充当事实。凡未经来源验证的内容，必须显式标注为推测。
