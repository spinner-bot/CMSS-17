## 二、候选域与要采集的内容

对下列每个域，采集：**该领域存在真实市场问题/未满足需求**的证据。

| # | 候选域 |
|---|---|
| D1 | **支付意愿与定价** —— 某类新兴消费品的价格接受度、价值感知 |
| D2 | **银发经济细分** —— 养老金融、适老化产品的成本与支付矛盾 |
| D3 | **地方产业 / 区域消费** —— 南京及江苏的文旅、农产品、夜间经济等 |
| D4 | **消费金融 / 居民理财行为** |
| D5 | **AI 产品的付费意愿与成本结构** |

**每个域采集三类证据**：
1. **问题存在的证据**：投诉数据、舆情、行业报告指出的痛点、政策文件点名的短板
2. **规模与趋势**：市场规模、增长率、渗透率（有具体数字）
3. **既有研究**：已有哪些调研/报告做过类似题目（判断撞车风险）

**另请自由扩展**：若在上述 5 域之外发现**明显的、有证据支撑的市场调研机会**，请一并提出。
