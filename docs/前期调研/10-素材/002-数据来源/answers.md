# 通用数据来源与合规边界手册

核查日期：2026-10-15（Asia/Shanghai）

> 本文提供选题无关的渠道地图和研究流程筛查原则，不构成法律意见。法律章节只依据现行法律原文和最高人民法院/法院官方案例资料。平台功能、价格及条款持续变化，真实采集前必须复核对应平台当日规则。每题均给出来源编号及证据强度；完整来源链接在 `sources.md`。

## A. 公开统计与政府数据

### 1. 中国主要官方统计数据源、颗粒度、更新频率和获取方式

**结论：**首选国家统计局数据发布库、统计公报/年鉴及主管部委和省市统计局。国家统计局提供宏观、人口、工业、消费、价格、就业收入等指标，按月、季度、年度发布，具体更新按指标发布日程；数据库支持网页检索，年鉴、公报提供下载/出版物。部委数据按职责覆盖财政、商务、教育、交通、农业、卫生等主题；地方统计局及地方年鉴提供省、市及部分区县层级，更新频率和可得粒度因地区及指标而异。公开目录不等于微观原始数据；统计调查个体资料依法受保密限制，引用时记录口径、单位、地区、时间和修订时间。国家统计数据以国家统计局公布的数据为准。

来源：S01–S04、S41；强。

### 2. 政府开放数据平台及原始数据可下载性

**结论：**可从国家数据局的国家公共数据资源登记平台发现资源，并继续访问省级/城市/部门数据开放平台。登记平台展示登记主体和资源信息，功能定位是登记和发现，不应误称全量数据下载库。各地开放平台提供目录、文件下载或API的情况不统一；有些资源需注册、申请或经授权运营后使用，格式可能为CSV、XLSX、JSON、PDF等，必须在具体数据集页面逐项确认。官方文件显示国家与省级平台按两级架构互联；“有登记”不表示“可下载”或“无条件免费”。

来源：S04、S42、S43；强。

### 3. 国际数据源对中国议题的可用性

**结论：**世界银行WDI、OECD Data Explorer、IMF Data可用于国际比较及中国国家级宏观/金融序列；是否覆盖中国、具体历史长度、更新时间和细分变量按数据库/指标查看。常见颗粒度为国家—年份/季度，通常不足以替代中国城市、个体或企业级数据。世界银行、OECD与IMF的公开数据库大多可网页查询和导出，但许可与具体产品条件需逐项核实；预测值、修订值应标注数据库版本和下载日期。

来源：S05–S07；强（数据源官方入口）；具体指标覆盖须逐项核验。

## B. 企业与行业数据

### 4. 上市公司数据合法渠道及批量下载

**结论：**法定披露首选上海证券交易所、深圳证券交易所及巨潮资讯网，可按证券代码/公告类型检索并下载年报、财报、临时公告。公开网页检索和逐份下载可用；本次未核实到公众可无限量使用的免费全量批量API。大规模自动下载、数据库再发布或商业使用需检查网站条款、接口授权和著作权/数据库权利，优先采用学校图书馆订阅数据库或经授权接口。建议保留公告发布日期、报告期、版本及下载链接。

来源：S08–S10；强。

### 5. 企业工商信息公开范围与限制

**结论：**国家企业信用信息公示系统可查依法公示的企业登记、年报公示、经营异常、行政处罚、许可等信息。系统并非企业全部经营、财务、交易或人员数据仓库；年报中的企业填报信息需识别其披露性质。天眼查/企查查等商业平台聚合公开及授权数据，其访问/导出权限受其用户协议、许可和套餐约束；“页面可见”不自动赋予批量复制、再分发或建立商业数据库的权利。避免收集企业负责人、个体经营者等自然人的非必要个人信息。

来源：S11、S21、S23；强（法律及官方登记入口）；商业平台细节依其当期合同。

### 6. 行业数据来源及付费情况

**结论：**可依次查主管部门统计、行业协会官网、交易所/企业披露、研究机构报告。协会年报、新闻稿和行业月报常公开摘要或汇总口径；完整报告、明细数据、会员库或定制研究可能收费/限会员。引用市场规模、渗透率等二次估算时，需追溯原始口径、统计对象和计算方法，不能将研究机构估算写成官方统计。

来源：S02–S04、S08–S10；强/中。协会和研究机构的数据许可需逐个核查。

### 7. 免费、可批量获取的企业/行业接口

**结论：**存在少量面向明确授权场景的官方开放API（例如交易所/部委特定数据服务、平台商家或开发者业务接口），但没有核实到覆盖中国全部企业/行业、免费、无限量且允许任意研究/再分发的通用接口。公司披露网站可批量逐份下载不等于API授权；接口额度、用途、身份和再利用权须分别核验。低成本基线是官方网页和文件逐份下载、限定样本、建立来源台账，或通过学校订阅资源使用许可数据库。

来源：S08–S11、S12–S20；强。通用无限量API未能核实。

## C. 社交媒体与用户生成内容（重点）

### 8. 主流平台官方开放API、门槛和可取数据

**结论：**平台开放接口主要服务已认证开发者、商家/创作者工作流，并通过OAuth、用户/商家授权、scope审核及调用额度控制；不能据此推定存在面向学生的全站舆情抓取接口。

### 9. 爬虫法律边界：现行法条与判例

**结论：**“网页公开可见”不是无限采集、画像、存储、出售或用于训练的总许可。首先适用个人信息保护、数据安全、著作权/合同等规则；若以经营者身份获取、使用他人合法持有数据，现行《反不正当竞争法》（2025修订，自2025-10-15施行）第十三条禁止以欺诈、胁迫、避开或破坏技术管理措施等不正当方式实施并损害权益、扰乱竞争秩序的行为。是否违法依事实综合判断，不能概括为所有爬虫一律违法或一律合法。

可核实判例包括：①最高人民法院2025年典型案例“搬家软件盗图抄店”不正当竞争纠纷，江苏高院（2024）苏民终212号，软件绕过验证/反爬措施抓取海量电商商品数据并迁移经营，二审认定不正当竞争并维持500万元赔偿；②最高人民法院2023年反垄断和反不正当竞争典型案例中的数据抓取案，法院保护平台经投入收集、存储、加工形成的数据集合合法权益；③最高人民法院知识产权法庭2025年典型案例“爬取网络平台数据不正当竞争案”强调区分公开、附条件公开和非公开数据，审查获取手段、协议、授权和实际用途。

研究团队应采取保守红线：不绕过登录、验证码、付费墙、反爬或频率限制；不使用泄露凭证；不抓取非公开/敏感个人信息；不造成服务负载；不传播或出售原始个人级数据；无法确认许可时向平台申请书面授权，或转用官方工具、样本服务和自采一手数据。

来源：S21–S26；强。

### 10. 平台用户协议、robots.txt与采集限制

**结论：**平台服务协议/开发者协议/API规则对账号使用、接口调用、自动化访问、数据留存与再利用设定合同和技术条件；应逐个平台、逐接口核对当期文本。robots.txt是网站向自动化访问者表达路径规则的技术约定/信号，不是个人信息、著作权或反不正当竞争法的豁免，也不能单凭其未禁止某路径就推导已获授权。平台条款、robots规则与法定义务并行，禁止绕过技术控制并遵守频率限制；本次没有逐一留存全部中文平台最新协议及robots.txt快照，故不声称每个平台具体条文相同。

来源：S12、S14–S20、S23–S26；强/中。逐站条款快照待具体项目再核验。

### 11. 合法替代方案

**结论：**优先级建议为：平台官方开发者/API（应用审核与授权）、平台官方商业数据/创作者后台、官方市场洞察工具、平台服务市场中合同明确的数据服务商、经合法样本库招募的一手问卷/访谈、政府开放数据及企业自愿授权数据。第三方服务商只有在数据来源、授权链、个人信息处理角色、留存/删除、再利用和成果权属写清楚后才可采用；供应商声称“公开抓取/合规”不是充分证据。

来源：S12–S20、S29–S34；强（官方平台能力及服务条款）；对具体服务商合规需合同审查。

## E. 一手数据采集工具

### 14. 问卷平台能力、样本、防刷、导出、费用；重点 Credamo

**结论：**问卷星、腾讯问卷和 Credamo 见数均可提供在线问卷或样本招募，但应把“问卷工具”和“样本服务”分开评估。问卷星样本服务按有效答卷计费，基础价格受题量影响，地区、特定人群、低样本量和加急等可能增加费用；腾讯问卷样本服务按题量、标签/筛选服务和实际回收结算，支持CSV/SAV导出，并有登录、规则校验和无效答卷控制；Credamo官网展示样本库、问卷/实验/访谈及价格估算，实际价格随目标人群和项目条件变化，公开“低至”宣传价不能作为特定项目报价。

**样本质量判断：**这些服务平台的样本库及质控能力描述主要是供应商自述，不能代替外部质量审计。询价时要求说明抽样框及招募渠道、样本来源地区/年龄覆盖、配额、去重机制、设备/IP或账号校验、注意力题/时长规则、无效样本剔除、激励方式和退款规则。市场调查报告应披露样本来自自愿在线面板，而非概率样本时，不可直接代表全体人口。

来源：S29–S34；强（平台官方信息）；样本质量是平台披露，非独立审计结论。

### 15. 实地访谈/观察采集工具与规范

**结论：**采用录音笔/手机、结构化访谈提纲、观察记录表和加密存储即可，不必先建设复杂系统。开始前说明研究目的、是否录音、用途、引用方式、保存期限和退出方式；取得知情同意。只记实现研究目的必需的信息，优先不采姓名、联系方式、精确住址；涉及敏感个人信息或未成年人时，避免采集，确需处理必须满足更严格法定条件。访谈结束后尽快去标识化，身份映射表与研究材料分开加密保存，限定访问者和删除时间；报告引用应匿名且避免组合线索重新识别。观察公共场景也不得据此任意识别、跟踪个人。

来源：S21–S22；强。

## F. 合规红线（重点）

### 16. 个人信息保护法、数据安全法对市场调查项目的约束

**结论：**《个人信息保护法》第4条界定个人信息为与已识别或可识别自然人有关的信息，匿名化后信息不属个人信息；第13条要求具备法定处理基础（同意只是其中一种，项目不能自行假设研究用途当然免责）；第17条要求处理前履行告知；第27条对个人自行公开/其他合法公开信息只允许合理范围处理，个人明确拒绝时不得继续，处理对个人权益有重大影响时需取得同意；第28—30条对敏感信息要求特定目的、充分必要、严格保护，并按规定取得单独同意/告知；第73条匿名化要求无法识别且不能复原。移除姓名通常只是去标识化，不一定匿名化。

《数据安全法》第27条要求全流程安全管理和必要技术措施，第28条要求数据处理和新技术研究开发符合社会公德与伦理。实操上需做最小化收集、访问控制、加密/脱敏、保存期限管理、风险评估，并限制原始数据共享/跨境。若走统计或学术研究处理基础，应逐项核验法定适用条件，不能把学生项目自动视为例外。

来源：S21–S22；强（法律原文）。

### 17. 反不正当竞争法与爬虫判例

**结论：**截至2026-10-15应适用2025年修订、2025-10-15施行的《反不正当竞争法》。第13条明确规制通过数据/算法/技术/平台规则妨碍网络服务正常运行的行为，并禁止以欺诈、胁迫、避开或破坏技术管理措施等不正当方式获取、使用其他经营者合法持有的数据，损害权益并扰乱竞争秩序；第29条规定相应行政处罚。该条适用于法定构成条件，不是笼统的“爬虫禁令”。

判例：江苏省高院（2024）苏民终212号“搬家软件盗图抄店”案；最高人民法院2023年反垄断和反不正当竞争典型案例中的数据抓取案件；最高人民法院知识产权法庭2025年典型案例“爬取网络平台数据不正当竞争案”。判例强调数据性质、公开状态、获取方式、技术措施、协议授权、使用场景、替代/损害效果等因素。研究者不应绕过访问控制或抓取平台用户个人信息。

来源：S23–S26；强（现行法律和法院官方案例）。

### 18. 生成式AI处理、文本分析及赛事披露

**结论：**使用生成式AI清洗/归类文本时，仍须确保输入数据来源合法、符合平台和数据集许可证；向第三方模型提供受限数据或个人信息前需确认服务商处理条款、保存/训练用途和数据区域，先最小化并去标识化。若团队作为生成式AI服务提供者，另受《生成式人工智能服务管理暂行办法》约束；学生使用既有服务时，仍须遵守个人信息、数据安全、著作权和服务协议。AI生成合成内容公开发布适用《人工智能生成合成内容标识办法》的相应主体义务。竞赛是否要求披露AI辅助及披露格式，应查当届大赛AI规范和参赛承诺书；本手册没有推定全国统一的学生披露规则。第十六届赛事材料目录已出现AI工具使用规范附件（DEPLOY-001来源S11），第十七届具体要求需以正式文件为准。

来源：S21–S23、S27–S28及 `docs/前期调研/10-素材/001-赛事基础/sources.md` S11；强/中。第十七届AI条款未能核实。

## G. 数据质量评估

### 19. 数据源可用性评估维度

**结论：**每个候选数据源按以下维度逐项记录，并用“可用/有条件/不可用”作决定：

| 维度 | 核查问题 |
|---|---|
| 权威性与来源链 | 谁采集、谁发布、能否追溯原始定义和生成过程？ |
| 时效性 | 更新时间、采集日期、是否滞后/修订/过期？ |
| 颗粒度与覆盖 | 地区、时间、行业、人群是否匹配目标总体？关键群体是否缺失？ |
| 可得性与稳定性 | 可否依法访问/下载，格式能否处理，接口是否稳定、是否有配额？ |
| 成本与许可 | 直接费用、人力/清洗成本、著作权/数据库许可、是否允许研究和展示？ |
| 合规性与伦理 | 是否含个人/敏感信息、是否获授权、是否需要伦理审查/单独同意？ |
| 质量与偏差 | 缺失、重复、异常、测量误差、代表性、选择偏差如何？ |
| 可复现性 | 是否能保存版本、查询条件、下载日期、代码本及处理步骤？ |

建议在团队的L2评分表中对“合法可得性”和“目标总体匹配”设否决项，不能用高样本数弥补来源不明或授权缺失。

### 20. 常见数据陷阱与例子

**结论：**

| 陷阱 | 例子 | 处理办法 |
|---|---|---|
| 自愿样本/选择偏差 | 在高校群转发问卷，回答者更可能是高参与度学生，不能代表全体青年消费者 | 明确抽样框，分层/配额招募并报告局限；可与官方人口结构对照 |
| 平台覆盖偏差 | 只分析抖音或小红书用户，结论只能描述该平台可触达用户，不代表全体消费者 | 将目标总体限定为平台用户，或补充线下/多平台样本 |
| 幸存者偏差 | 只访谈仍在经营的店铺，会漏掉已倒闭者及失败原因 | 纳入退出/关停样本或使用工商状态、历史名录构建抽样框 |
| 非应答偏差 | 低收入、忙碌或网络可及性差的人群更少完成在线问卷 | 记录响应率，设计适龄渠道和回访，分析非应答可能性 |
| 相关不等于因果 | 有优惠券的用户购买更多，可能是高意愿用户更常领券 | 不把横截面相关写成政策/营销因果；用实验或合理识别设计 |
| 指标/口径错配 | 不同年份“网络零售额”或企业行业分类变更，直接拼接可能制造趋势 | 核对元数据、修订说明、分类版本与单位，必要时断点处理 |
| 重复/低质答卷 | 同一人多次填答、直线作答、极短时长、逻辑矛盾 | 预设去重和质控规则、保留剔除日志、报告有效样本数 |
| 生态谬误 | 省级平均收入与省级购买意愿相关，被误说成个人收入导致购买 | 区分分析层级，个体结论用个体数据验证 |
| 发布/幸存者筛选 | 只看公开成功案例或平台推荐内容，忽略未发布和失败案例 | 说明检索策略、抽样边界，结合多种来源验证 |

以上是方法学示例，不是具体行业事实判断。
