摘要 Executive Summary

本报告用客观事实推导选题，而非为既定选题背书。调研沿 L0 约束识别 → L1 机会识别 → L2 数据可行性 → L3 技术可行性 → L4 竞品扫描 → L5 方向收敛 的链条逐级推进，每一级结论均有来源与证据强度标注。

核心结论：推荐方向簇 —— 以「价值—价格」为核心视角的消费市场调查；主推方向为 「二手商品的成色认知与折价机制」，备选可低成本切换至「以旧换新折价感知」或「新品质价比与溢价边界」。

三条关键依据：

① 评分表把 65 分给了调研执行（方案设计 20 + 调查实施 20 + 分析与结论 25），而「研究创新」仅 3 分 —— 本赛事奖励扎实的调查，不奖励技术炫技。

② 团队的稀缺性是财务专业纵深，而非 AI 技术。「价值—价格」恰是财务训练能直接变现、而多数参赛队做不到的分析层次。

③ 赛场上存在真实空白：无论正大杯既有作品还是业界实践，二手/消费领域几乎无人从「定价与价值」角度切入。

1 · 调研背景与方法

团队尚未确认选题方向。本调研的目的，是用客观事实把选题推导出来 —— 而非先有方向再找证据。

1.1 证据分级标准

报告中每一项事实性结论均标注来源与证据强度。强 官方文件、主办方发布的章程或评分表、法条原文；中 高校官网通知、权威媒体报道、券商与咨询机构报告；弱 自媒体、论坛、二手转述。强度为「弱」的结论不得作为方向决策依据。

方法说明

本调研采用「主干—支线」双工作流：关键路径上的判断与分析由主负责人独立完成，体量大的素材采集可并行外包，但不阻塞主干推进。本报告的全部结论均出自主干路径。

3 · 市场机会识别（L1）

3.1 先修正一个方向性错误

立项时的表述是「解决真实运营环境下的痛点」，这容易把方向引向创业式思维 —— 找一个痛点做一个解决方案。但 L0 的证据不支持这个框架：获奖作品清一色是市场调查，是研究，不是产品方案。评分表也印证 —— 25 分给的是「分析与结论」，而非「方案有多完整」。

因此本层的目标修正为：不找「痛点 + 解决方案」，而找「一个值得做、做得出、析得深、还不算撞车的调研命题」。

3.2 核心发现：一个被整个赛场忽略的角度

正大杯获奖选题的分析落脚点绝大多数是意愿（购买意愿、参与意愿、采纳意愿）、满意度、影响因素。而评分表把 25 分给了「分析与结论」。

谁能把「价格 / 成本 / 价值」这条财务—经济学的分析线做进来，谁就天然多一层别人做不出的深度。

3.3 候选命题

★ P1 · 二手商品的成色分级与折价机制

真实痛点（有硬数据支撑）

  • 卖方首要痛点：平台同品定价不一、价格难把控且易被砍价 —— 58.49%中
  • 商品质量分级标准缺失，"轻微使用痕迹"等模糊表述导致"定价无据、维权无门"中
  • 买方 55.62% 遇信息不透明或卖家隐瞒成色中
  • 同一 95 新 LV 包不同渠道售价 1.05–1.6 万元；同型号二手手机因外观配件差异价差 30%–50%中

行业现状（可支撑深度分析）

  • 成色体系极不统一：6 级制（衍生出 9 级）vs N/S/A/B 四级制
  • 头部平台正通过深化等级压缩价差：爱回收从 ABCDE 五级 → 36 个质检等级
  • 保值率参考（奢侈品）：N 级 100–110%、S 级 85–100%、A 级 70–85%、B 级 50% 以下；差一级价差 20–50%，N 级与 B 级极端可差 3 倍
  • 附件齐全比裸包贵 20–30%；硬伤每项降价 500–800 元中

政策时机：发改委《循环经济发展"十五五"规划》明确"规范二手商品流通交易发展"；团体标准《品牌消费品鉴定通用技术规范 外观成色定级》已立项（P/CIQA-226-2025）。中

○ P2 · 新消费品的质价比感知与支付意愿

  • 2026 快消市场「量增价跌」：销量 +3.6%，均价 −2.6%中
  • 价格带「哑铃化」：高端与极致性价比两端增长，中间价格带承压中
  • 76% 消费者愿为安全溯源、匠心工艺、情绪治愈支付合理溢价；68% 建立月度预算台账，71% 跨平台比价中

○ P3 · 消费品以旧换新中的折价感知

国家「以旧换新」为 2025–2026 国策，覆盖家电、汽车、数码。与 P1 共享"旧物折价"内核，场景换成政策驱动。

○ P4 · 二手消费品的「保值 / 投资」属性

从投资学视角研究二手奢侈品/潮玩的保值属性。差异化强，但目标人群小众，样本获取是主要风险。

3.5 L1 结论

收敛到一个共同底座：以「价值—价格」为核心视角的消费市场调查 —— 不研究"消费者喜不喜欢"，而研究"消费者认为值多少钱、为什么值这个价、怎么定价才合理"。P1–P4 是这个底座在不同场景下的展开。

4.1 三条关键风险

  1. P1 的最大风险是抽样。二手研究的既有作品几乎全部陷在"大学生样本"里 —— 这既是它们撞车的原因，也是它们分析浅的原因。若主推 P1，抽样方案必须突破校园人群。这恰是「方案设计（20 分）」要解决的问题。
  2. 平台数据的合规边界须先厘清。建议以一手调研为数据主体，平台信息仅作公开可见内容的轻量采样，不采用批量爬取。
  3. D7 可验证性普遍较高意味着这些领域都有公开行业报告 —— 若研究只重复公开结论就没有增量，必须靠一手数据做出公开报告没有的东西。

5 · 分析方法可行性（L3）

5.1 本项目里的「技术」是什么

在这个赛事里，「技术可行性」不是指 AI 模型能力 —— L0 已证明「研究创新」只占 3 分，AI 只能是提效工具。真正的技术 = 分析方法能做到多深，而「分析与结论」值 25 分，是全表单项最高。

方法用途适配难度
特征价格模型 Hedonic Pricing把价格分解到各属性（成色、品牌、附件、瑕疵）的边际贡献P1中高
联合分析 Conjoint测算各属性对消费者效用的权重，反推支付意愿P1、P2高
Gabor-Granger / Van Westendorp价格阶梯测试，找最优价格点与可接受区间P2、P3中
多元回归 / 逻辑回归影响因素分析（常规但可靠）全部低
结构方程模型 SEM多路径机制检验P1、P2中高
🔑 特征价格模型是 P1 的杀手锏

它把「成色值多少钱」从主观经验变成可估计的边际价格 —— 而行业痛点正是"定价无据"，这个方法直接产出一个"有据"的定价参照。

该方法在房地产、汽车残值领域成熟，在二手消费品领域应用极少 —— 既有方法论的扎实性（不会被质疑），又有应用场景的新颖性。

团体标准《品牌消费品鉴定通用技术规范 外观成色定级》编制中尚未发布，且侧重"定级"而非"定价"
🔑 关键空白

所有既有努力都在「如何更准确地给商品定级」（供给侧的质检问题），却几乎没有人研究「消费者如何把成色转化为价值判断」（需求侧的价值认知问题）。

这正是本项目的位置：从消费者侧回答"成色到底值多少钱"。而 58.49% 的卖方痛点（价格难把控）恰恰源于「平台定级」与「用户感知」之间的错位。

6.3 学术方法渊源

特征价格模型（Hedonic Pricing）由 Rosen (1974) 奠基，广泛应用于房地产、汽车、葡萄酒等差异化商品定价。在二手消费品（尤其奢侈品、3C）上的实证应用很少 —— 引用成熟方法 + 新应用场景，是「文献研究（7 分）」的稳妥打法。

7 · 方向簇建议与论证（L5）

本章为报告核心

不收敛到单一选题，而是提出一组共享同一分析底座、可低成本互相切换的方向 —— 因为数据可得性是本项目最大的不确定性，单一选题一旦受阻就要全盘重来。

7.1 共同底座

以「价值—价格」为核心视角的消费市场调查

不研究"消费者喜不喜欢"，而研究"消费者认为值多少钱、为什么值这个价、怎么定价才合理"。

这个底座的三重合理性：

  1. 对齐评分表 —— 「分析与结论」占 25 分，是单项最高。以"价值/价格"为被解释变量的分析天然需要较深建模，远高于"满意度打分 + 交叉表"的常规做法。
  2. 对齐团队禀赋 —— 沈舒畅的 ACCA 训练（成本、财务、会计、投资、税务）是价格与价值分析的专业基础。多数参赛队由统计或营销背景组成，做得了问卷，做不了价值分析。
  3. 对齐赛场空白 —— L4 扫描显示，无论正大杯既有作品还是业界实践，都罕见从"价值—价格"切入。

7.3 各方向详述

D1 · 成色认知与折价机制

消费者在二手交易中对"成色"的价值判断，与平台定级体系之间存在系统性错位。本项目拟通过估价实验与问卷，采集消费者对不同成色商品的支付意愿，结合平台公开在售信息，用特征价格模型估计"成色—价格"的边际映射关系，并检验"平台定级"与"用户感知"的偏差。

D2 · 以旧换新折价感知

在国家以旧换新补贴政策下，消费者的实际到手价由"旧物折价 + 政策补贴"构成。本项目研究消费者对旧物折价的感知是否理性、补贴是否被商家的低折价所吸收，以及消费者如何评价"以旧换新"的真实优惠力度。

D3 · 质价比与溢价边界

在价格带"哑铃化"的结构下，中间价格带产品承压。本项目用联合分析或价格测试方法，测算消费者为安全溯源、匠心工艺、情绪价值等属性愿意支付的溢价上限，为"质价比"提供可量化的边界。

D4 · 保值 / 投资属性

从投资学视角，检验二手奢侈品或潮玩是否具备保值甚至投资属性，其定价逻辑与金融资产的异同。差异化强，但目标人群小众，样本获取是主要障碍。

7.5 切换成本评估

这是方向簇存在的意义 —— 若主推方向在数据采集阶段受阻，可低成本转移：

切换路径成本说明
D1 → D2极低同是"旧物折价"，仅将场景从"二手交易"换成"以旧换新"，问卷主体与模型可复用
D1 → D3低同是"价值—价格"，仅将对象从"二手商品"换成"新品"；特征价格模型可平移
D1 → D4中研究对象不变，但分析视角从"折价机制"换成"保值/投资属性"，需重构理论框架
D2 → D3中高共同底座仍在，但数据与场景全部更换

结论：若主推 D1 受阻，可低成本切换到 D2 或 D3 —— 三者共享"价值—价格"底座与大部分方法工具，前期投入不会浪费。
