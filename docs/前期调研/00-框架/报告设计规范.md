# 前期调研报告 · HTML 设计规范

**性质**：Claude Code 独家设计（视觉判断不可外包）
**日期**：2026-10-15
**交付物**：`docs/前期调研/90-交付/前期调研报告.html`

---

## 一、设计定位

**读者**：团队成员、指导教师、赛事评委（潜在）。
**目标**：让一份**调研报告**读起来像**严谨的研究成果**，而不是学生作业。

**基调**：学术严谨 + 数据驱动。**不采用**赛博朋克霓虹风——那是个人主页的语言，用在这里会削弱可信度。视觉的克制本身就是专业性的表达。

---

## 二、结构

```
封面          — 报告标题、副标题、团队、日期、作者链接
摘要 Executive Summary — 一页读完：结论、依据、方向建议
目录          — 可点击跳转
第 1 章 调研背景与方法   — 含 L0–L6 逻辑链条说明、证据分级标准
第 2 章 赛事约束分析     — L0
第 3 章 市场机会识别     — L1
第 4 章 数据可行性       — L2
第 5 章 技术可行性       — L3
第 6 章 竞品与差异化     — L4
第 7 章 方向建议与论证   — L5（核心章节，篇幅最重）
第 8 章 风险与执行路径   — 含未验证假设清单
参考文献          — 编号、标题、URL、访问日期、证据强度
附录          — 原始材料索引
```

**证据强度必须在正文中可见**：引用处用角标（如 `[12·强]`）标注来源编号与强度，弱证据结论须在文中显式声明"证据强度：弱"。

---

## 三、视觉系统

**配色**（低饱和、高对比、可打印）

| 用途 | 色值 |
|---|---|
| 正文 | `#1a1a1a` |
| 次要文字 | `#5a5f66` |
| 主强调色 | `#1f4e79`（深学术蓝） |
| 次强调色 | `#c0504d`（用于风险、警示） |
| 分隔线 / 边框 | `#e3e6ea` |
| 页面背景 | `#ffffff` |
| 引用块背景 | `#f7f8fa` |

**排版**
- 正文最大宽度 `760–820px`，居中。
- 字体：中文 `"Noto Serif SC", "Songti SC", serif` 为主；数据与英文用 `"Inter", -apple-system, sans-serif`。
- 行高 `1.8`，段间距 `1em`。**正文不使用彩色文字**。
- 章节标题左侧配一条 `3px` 竖条（主强调色），层级清晰。

**证据强度徽章**：`强 / 中 / 弱` 三种小徽章，绿 / 灰 / 橙，统一圆角 `3px`，字号 `0.75em`。

---

## 四、图表规范

- 全部图表**内联 SVG**，不依赖外部 CDN（保证离线可开）。
- 图表必须**自解释**：有标题、单位、坐标轴标签、数据来源脚注。
- 配色沿用上述色板，**不使用彩虹渐变**。
- L0–L6 逻辑链条用一张**流程图**呈现（总纲的表格可视化）。

## 六、技术约束

- **单文件 HTML**，内联 CSS 与 SVG，无外部依赖 —— 双击即可打开，便于提交与传阅。
- 响应式：窄屏（<768px）单栏，图表可横向滚动。
- 打印友好：`@media print` 下隐藏目录互动元素，保留配色。
