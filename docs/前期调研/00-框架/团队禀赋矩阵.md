## 三、关键判断

### 判断 1：团队的商科底色是「会计 / 财务」，不是「市场营销」⚠️

这是本次分析最重要的发现。

正大杯考察的是**市场调查**——核心方法是问卷设计、抽样理论、消费者行为分析、统计推断。而这个团队的专业训练集中在**会计与财务**，**没有任何人受过市场营销或市场研究的系统训练**。

**推论**：
- **不能再假定"有 3 个商科学生 = 市场调研能力强"**。商科 ≠ 市场调研，二者之间的缺口是真实存在的。
- 选题若落在"消费者行为洞察"这类纯营销赛道，团队是**以短击长**。
- 这个缺口必须在 L1 阶段通过**方法学习**或**引入外部指导**来补，否则会成为致命伤。

### 判断 2：真正的稀缺性是「财务视角 × AI 工程」的组合 ✅

市场上绝大多数参赛队是：营销/统计背景做过市场调研，但技术实现粗糙；或计算机背景能做模型，但商业洞察浅。

这个团队的独特组合是：
- **财务/成本/税务的专业纵深**（沈舒畅的 ACCA 训练，本科生里少见）
- **实打实的 AI 工程能力与超算资源**（张锐寒）
- **实地调研的执行力**（刘诗蓉）

**推论**：选题若能设计成**「用 AI 方法解决一个需要财务纵深的真实问题」**，则同时命中两个稀缺性，形成"不可替代性"。这是 L5 收敛时的主要假设方向之一。

### 判断 3：能力断层必须被设计规避

商科三人的编程能力是"Python 基础数据处理"。**任何需要持续工程开发的方向都会压垮张锐寒一人**，且赛程紧张时无人可替换。

**推论**：技术方案必须满足 **"单人在有限时间内可交付"**。宁可方法精巧而实现轻量，不可方法宏大而工程沉重。

## 四、待补充的信息缺口

以下信息缺失，会限制后续判断的精度。**建议在 L1 启动前补齐**（不阻塞 L0）：

1. **杨芮的能力画像完全空白** —— 她"有相关项目经验"，但项目是什么、她负责什么？这直接影响任务分配。
2. **答辩与人际能力**：谁适合主讲答辩？报告撰写之外，现场表现是重要得分项。
3. **指导教师情况**：是否有指导教师？其研究方向是什么？（可能是重要的资源或约束）
4. **可投入时间**：赛程跨度内，四人各自每周可投入多少小时？这决定方向的时间可行性。
5. **是否有前期积累**：团队是否已有部分调研数据、行业资源、人脉？

> 这些问题 Claude Code 无法自行查证，已在此列出。若用户未提供，L5 收敛时应将对应风险显式标注为"未验证假设"。

## 五、对 L1 调研方向的约束（下发前约束）

基于以上，L1「机会识别」的候选方向应满足：

1. **可产出结构性数据**（问卷、公开统计、文本/评论），而非依赖难以获取的内部数据。
2. **能给财务/成本维度留出分析空间**，让沈舒畅的专业能力变成得分点，而非摆设。
3. **技术实现轻量**，张锐寒单人在赛程内可完成。
4. **不假设团队具备市场营销理论**，或明确规划了补足路径。
